# Use wrap-check in Claude Desktop

Use this reference when the desktop session tools are available.

- Resolve another session with `mcp__ccd_session_mgmt__list_sessions` and read its history with `mcp__ccd_session_mgmt__list_events`. Use `mcp__ccd_session_mgmt__get_session` for its working directory and owned worktree. Use `self` for the current session where supported.
- Check the state of background work and linked sessions. Use `mcp__ccd_session_mgmt__list_sessions` with `linked: true` to fill a gap or refresh stale session state, and check GitHub with `gh` when review state is missing or stale. Treat archiving as removing the session-owned worktree unless the app reports it will retain it. Keep the session open if this would discard work or if active work prevents archiving.
- After the verdict, use `mcp__ccd_turn__wrap_up` to ask **Archive this session?** with **Archive** and **Keep it** buttons for a session that is safe to archive. If there is work to continue here, offer its top next action and **Not now**. When local-only Git work blocks archiving, include the preservation step in that action, such as **Commit and push** after any remaining checks or edits. A blocker that only someone else can resolve needs no action card.
- Propose independent work with `mcp__ccd_session__start_session` only where the host supports an inert suggestion that requires a click to start. Use `initiation: "own_initiative"`, at most three cards, and prefer `context: "fresh"`. Put the task, files, completion criteria, and dependencies in `prompt`; supply at least 80 characters of context in `background`. Use `"fork"` only when the task needs the conversation and the conversation is short. If a suggestion would start work immediately, give a plain-text brief instead.
- After explicit archive authorization and a safety recheck, write the final message before calling `mcp__ccd_session_mgmt__archive_session` with the target `session_id` (`self` for this session) and a short `reason`. If the app refuses, report why.
